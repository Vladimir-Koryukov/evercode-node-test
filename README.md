# Evercode Node Test

Учебный проект

## Общее описание

- Фоновая синхронизация курсов валют с Binance раз в минуту
- Express web-сервер
- Публичный endpoint `/status`
- Авторизация через Bearer token
- CRUD API для валют
- Endpoint для получения сохранённых курсов валют из SQLite
- Пользовательские ошибки приложения
- Тесты на Jest и supertest
- OpenAPI- контракт для всех endpoint

## Хранение данных

Для хранения валют и полученных курсов используется SQLite.

Курсы обновляются при запуске приложения и далее раз в минуту. Сохраняются только валютные пары, относящиеся к добавленным валютам.

Перед запуском приложения нужно инициализировать базу данных командой `npm run db:init`

Файл базы данных создается локально по пути `database/app.db`

## Работа приложения

В корне проекта требуется создать файл `.env` и поместить в него токен длиной 64 символа:

AUTHORIZATION_TOKEN=64_symbols_token

Далее стоит инициализировать базу данных `npm run db:init`.

Для запуска сервера вместе с фоновой синхронизацией используется команда `npm start`. Сервер запускается по адресу `http://localhost:3001`.

Для отдельного запуска фоновой синхронизации без HTTP-сервера используется команда `npm run scheduler`.

Для запуска тестов `npm test`.

Защищенные endpoints требуют заголовок `Authorization: Bearer <token>`.

Описание всех endpoints находится в `src/docs/openapi.yaml`.
